# Caesar Cipher Tool

A desktop application implementing the classic Caesar Cipher encryption and decryption algorithm. This project focuses on string manipulation, character encoding mappings, and building an interactive multi-stage user interface using Python.

## 🚀 Key Features

- **Bi-directional Processing:** Easily switch between text encryption (shifting characters right) and decryption (shifting characters left).
- **Customizable Shift Key:** Supports any user-defined numeric step/offset to shift the alphabet dynamically.
- **Multi-Alphabet Support:** Engineered to handle character shifts while preserving case and ignoring non-alphabetic symbols (like spaces or punctuation).
- **Smooth Navigation:** Designed with wizard-like forward/backward navigation flow using clean state control.

## 🛠 Tech Stack

- **Language:** Python 3.11+
- **GUI Framework:** CustomTkinter
- **Architecture:** Object-Oriented Programming (OOP) with clean logical state branching.
